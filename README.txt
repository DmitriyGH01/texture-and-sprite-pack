Привет! Здесь я выкладываю свои авторские текстуры в формате PNG.
Проект периодически обновляется, заглядывайте за новыми ассетами!

----------------------------------------------------------------------
1. СТРУКТУРА ПАПОК И ФАЙЛОВ:
----------------------------------------------------------------------
- /textures-atlas : Текстурный атлас (спрайт-шит)
- /medieval-style : Текстуры в средневековом стиле (размер 100x100)
* В будущем будут добавляться новые папки с другими стилями.

----------------------------------------------------------------------
2. ТЕХНИЧЕСКАЯ ИНФОРМАЦИЯ ДЛЯ АТЛАСА (в папке /textures-atlas):
----------------------------------------------------------------------
- Все элементы внутри атласа строго выровнены по сетке 16x16 пикселей.
- При импорте в игровой движок (Unity, Godot и др.) используйте шаг 
  сетки 16x16 для автоматической нарезки спрайтов.
