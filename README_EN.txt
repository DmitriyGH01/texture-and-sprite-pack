Hi! Here I upload my custom textures in PNG format.
The project is updated periodically, so check back for new assets!

----------------------------------------------------------------------
1. FOLDER AND FILE STRUCTURE:
----------------------------------------------------------------------
- /textures-atlas : Texture atlas (spritesheet)
- /medieval-style : Medieval style textures (100x100 pixels size)
* New folders with other styles will be added in the future.

----------------------------------------------------------------------
2. TECHNICAL INFORMATION FOR THE ATLAS (in /textures-atlas):
----------------------------------------------------------------------
- All elements inside the atlas are strictly aligned to a 16x16 pixel grid.
- When importing into a game engine (Unity, Godot, etc.), use a 
  16x16 grid cell size for automatic sprite slicing.
